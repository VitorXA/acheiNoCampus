
# Achei no Campus

O Achei no Campus é uma aplicação web desenvolvida para facilitar a recuperação de objetos perdidos e encontrados dentro do ambiente universitário.

A ideia surgiu da necessidade de tornar mais simples a comunicação entre estudantes e outras pessoas da comunidade acadêmica que perderam algum pertence ou encontraram um objeto que pode ser de outra pessoa.

Por meio da plataforma, é possível consultar objetos registrados, procurar por itens específicos e contribuir com a comunidade compartilhando informações sobre objetos encontrados.

## Objetivo do projeto

O principal objetivo do Achei no Campus é oferecer um espaço digital acessível e organizado para ajudar na recuperação de objetos perdidos dentro da universidade.

A proposta busca reduzir as dificuldades enfrentadas por quem perde algum pertence, tornando o processo de busca mais prático e centralizado.

Além disso, o projeto incentiva a colaboração entre os membros da comunidade acadêmica, permitindo que todos contribuam para que objetos perdidos possam voltar aos seus respectivos donos.

## Funcionalidades

A aplicação está sendo desenvolvida para oferecer as seguintes funcionalidades:

- Consulta de objetos perdidos e encontrados.
- Pesquisa de objetos por nome ou descrição.
- Filtragem de itens por categoria.
- Visualização das informações dos objetos registrados.
- Registro de objetos encontrados.
- Interface adaptada para diferentes tamanhos de tela.

As funcionalidades de cadastro de usuários, autenticação e integração com banco de dados fazem parte das próximas etapas de desenvolvimento.

## Tecnologias utilizadas

O projeto utiliza tecnologias voltadas ao desenvolvimento web:

- HTML5 para a estrutura das páginas.
- CSS3 para estilização e organização visual.
- JavaScript para interatividade e funcionalidades da interface.
- Git e GitHub para versionamento e compartilhamento do código.

A aplicação também prevê a utilização de tecnologias para o desenvolvimento do backend e armazenamento de dados.

## Estrutura do projeto

O projeto está organizado da seguinte maneira:

```text
acheinocampus/
├── front-end/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
│
└── README.md
```

### Descrição dos arquivos

- `index.html`: contém a estrutura principal da aplicação.
- `css/style.css`: reúne os estilos responsáveis pela aparência e organização da interface.
- `js/script.js`: contém os códigos JavaScript utilizados para as interações e funcionalidades da página.
- `README.md`: apresenta informações sobre o projeto, seus objetivos e tecnologias.

## Como executar o projeto

Para visualizar a aplicação localmente, siga os passos abaixo.

1. Clone o repositório:

```bash
git clone https://github.com/VitorXA/acheiNoCampus.git
```

2. Acesse a pasta do projeto:

```bash
cd acheiNoCampus/front-end
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar a aplicação durante o desenvolvimento.

## Publicação

O frontend do Achei no Campus pode ser publicado utilizando o GitHub Pages.

A publicação permite que a aplicação seja acessada diretamente pelo navegador, sem a necessidade de executar o projeto localmente.
